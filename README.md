# Amalab downloads

Installers, Android APKs and update files for **Amalab**. The source code is not in this repository.

## templates/v1

Outline templates used by Amalab's Templates library (1,037 outlines). All artwork is **CC0 1.0 (public domain)**:

- **622 Amalab originals** (`by: "Amalab"` in `catalog.json`): apparel flats and product mockups drawn by
  Amalab's own generator — t-shirts, hoodies, polos, dresses, skirts, trousers, shirts, jackets, mugs,
  bottles, caps, bags, phone cases and more. See [templates/README.md](templates/README.md).
- **415 from [FreeSVG.org](https://freesvg.org)**; each item's source page is listed in `catalog.json`.
SVGs were cleaned (scripts, external links and editor metadata removed) and hand-reviewed.

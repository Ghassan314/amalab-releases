# Amalab template originals

The items marked `"by": "Amalab"` in `v1/catalog.json` were drawn by Amalab's own template generator
(apparel flat sketches and product mockups). They are dedicated to the public domain under
**CC0 1.0 Universal**: use, change, print and sell them freely — no credit needed.

Each outline is line art with a transparent inside, so it can be coloured on a layer underneath
and filled with Amalab's Smart Fill.

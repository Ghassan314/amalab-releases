# Amalab downloads

Installers, Android APKs and update files for **Amalab**. The source code is not in this repository.

## templates/v1

Outline templates used by Amalab's Templates library. All artwork is **CC0 1.0 (public domain)**,
collected from [FreeSVG.org](https://freesvg.org). Each item's source page is listed in `catalog.json`.
SVGs were cleaned (scripts, external links and editor metadata removed) and hand-reviewed.
